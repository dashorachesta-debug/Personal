Understand how RAG actually works

RAG retrieves relevant information from an external knowledge source at query time and provides that context to an LLM so it can generate a more accurate and grounded answer.

📚 Knowledge Base ✂️ Chunking 🔢 Embeddings 🗄️ Vector Store 🔍 Semantic Search 🎯 Reranking 🧠 LLM

RAG Architecture

Follow the data from ingestion to final generation.

1

Data Sources

PDFs, documents, websites, databases and enterprise data.

2

Clean & Chunk

Clean text and divide knowledge into manageable chunks.

3

Embeddings

Convert text chunks into numerical vector representations.

4

Retrieve

Perform semantic similarity search against the user query.

5

Rerank + Context

Prioritize the most relevant chunks and build the prompt.

6

LLM Generation

Generate a grounded answer using retrieved context.
